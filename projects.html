Agent Hypervisor

Runtime supervisor for multi-agent Shared Sessions with Execution Rings, Joint Liability, and Saga Orchestration. The governance layer that enforces what agents should do and what happens when they fail.

Key Features:

  • Execution Rings: CPU-ring-inspired privilege levels with dynamic elevation (TTL-bounded, like sudo)
  • Saga Orchestration: Parallel fan-out with ALL/MAJORITY/ANY failure policies and automatic compensation
  • Joint Liability: Shapley-value fault attribution — proportional blame, not binary
  • Shared Sessions: Vector clocks, intent locks, configurable isolation (SNAPSHOT/READ_COMMITTED/SERIALIZABLE)
  • Observability: Structured event bus with 40+ event types and causal trace propagation
  • Security: Per-agent rate limiting, breach detection with circuit breakers, kill switch with graceful handoff
🎯 v2.0: 326 tests • 17 source modules • 58 public API symbols • Zero external dependencies beyond Pydantic
