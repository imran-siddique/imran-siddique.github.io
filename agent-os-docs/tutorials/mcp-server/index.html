🌟 Overview

The complete Agent OS safety framework for Claude Desktop

The AgentOS MCP Server brings kernel-level agent governance directly into Claude Desktop. Instead of writing code or configuration files, simply describe what you want in natural language — Claude will create safe, policy-compliant agents with built-in safety guarantees.

⚡ Quick Start

Get up and running in under 2 minutes

Step 1: Configure Claude Desktop

Add to your claude_desktop_config.json:

📍 Config File Locations

  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "agentos": {
      "command": "npx",
      "args": ["-y", "@agentos/mcp-server"],
      "env": {
        "AGENTOS_POLICY_MODE": "strict"
      }
    }
  }
}

Step 2: Restart Claude Desktop

Close and reopen Claude Desktop to load the MCP server.

Step 3: Start Building Agents!

Just ask Claude naturally:

👤 You

Create an agent that backs up my Documents folder to Google Drive every night

🤖 Claude (using AgentOS)

✅ Agent Created Successfully!

Agent: documents-backup-agent
Schedule: Every day at 2 AM

Safety Policies Applied:

  • 🛡️ Cost Control: Max $10/day cloud storage
  • 🛡️ Data Protection: Encryption in transit
  • 🛡️ Audit Logging: All operations tracked

Would you like me to run a test backup first?
