AgentMesh

The Secure Nervous System for AI Agents

The protocols exist. A2A gives agents a common language. MCP gives agents tools. Neither enforces trust. AgentMesh is the governance layer that makes multi-agent ecosystems safe to scale.

15min Credential TTL
<5ms Policy Evaluation
<200ms Trust Handshake
5 Reward Dimensions
View on GitHub pip install agentmesh-platform
# Initialize a governed agent in 30 seconds
$ pip install agentmesh-platform
$ agentmesh init --name my-agent --sponsor alice@company.com

# Your agent now has:
# ✓ Cryptographic identity
# ✓ 15-min credential rotation
# ✓ Policy enforcement
# ✓ Tamper-evident audit logs

Four Layers That Compound

Each layer is independently useful but compounds when used together. The Reward Engine only works because Identity provides accountability.

4

Reward & Learning Engine

Continuous behavioral feedback loop with adaptive learning. Not static rules.

  • 5-dimension trust scoring
  • Auto credential revocation
  • A/B testing for weights
  • Explainable scores
3

Governance & Compliance

Declarative policies with automated compliance mapping.

  • YAML/JSON policies
  • EU AI Act, SOC2, HIPAA
  • Merkle audit chains
  • Shadow mode testing
2

Trust & Protocol Bridge

Unified trust across all protocols. One model, any protocol.

  • Native A2A support
  • Native MCP support
  • IATP handshakes
  • Protocol translation
1

Identity & Zero-Trust Core

First-class agent identity with human sponsor accountability.

  • Ed25519 cryptographic ID
  • 15-min credential TTL
  • Delegation chains
  • SPIFFE/SVID support

Why AgentMesh?

🔐

Human Sponsor Accountability

Every agent identity is cryptographically linked to a human sponsor. Delegation chains can only narrow, never widen.

⚡

Ephemeral Credentials

15-minute TTL by default. Automatic rotation. Instant revocation. No long-lived secrets.

🌐

Protocol-Native Trust

Native support for A2A, MCP, and IATP. Unified trust model regardless of protocol.

📊

Adaptive Learning

The Reward Engine learns from agent behavior. Not just static blocklists—continuous improvement.

✅

Compliance Automation

Automatic mapping to EU AI Act, SOC 2, HIPAA, and GDPR. Generate audit reports instantly.

🔗

Tamper-Evident Audit

Merkle-chained audit logs. Any modification is detected. Verify integrity offline.

Built on Agent OS

AgentMesh is the platform layer built on top of the Agent OS kernel.

# Dependency chain

agentmesh-platform (1.0.0a1)
└── agent-os-kernel[nexus,iatp] (1.2.0)
    ├── IATP protocol implementation
    └── Nexus Trust Exchange

# Think of it like:
# Agent OS = Linux kernel (low-level primitives)
# AgentMesh = Kubernetes (platform orchestration)

Get Started

The agents are shipping. The governance layer wasn't. Now it is.

$ pip install agentmesh-platform
$ agentmesh init --name my-agent --sponsor you@company.com
